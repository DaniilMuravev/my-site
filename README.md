# Сайт с приложениями: деплой на Vercel

## Что внутри
- `index.html` — весь сайт: портфолио, итоги чатов, прожарка канала
- `api/ai.js` — серверная функция для AI-шуток через GigaChat
- `.env.example` — какие переменные нужны

## Шаг 1. GitHub
1. Создай репозиторий на github.com, например `my-site`
2. Загрузи туда все файлы из этой папки (кнопка «Add file → Upload files»), сохрани структуру: папка `api` с `ai.js` внутри

## Шаг 2. Vercel
1. Зайди на vercel.com через GitHub
2. «Add New → Project», выбери репозиторий, ничего не меняй, жми «Deploy»
3. Через минуту будет ссылка вида `my-site.vercel.app`. Сайт уже работает, просто без AI

## Шаг 3. GigaChat
1. Зайди на developers.sber.ru через СберID, создай проект GigaChat API (тариф для физлиц, Freemium)
2. В проекте получи «Ключ авторизации» (Authorization key)
3. В Vercel: проект → Settings → Environment Variables. Добавь `GIGACHAT_AUTH_KEY` со значением ключа
4. Deployments → у последнего деплоя «Redeploy»
5. Проверка: открой `my-site.vercel.app/api/ai`. Должно быть `{"ok":true}`. Потом нажми «AI-прожарка» на сайте

Если AI не отвечает, открой в Vercel вкладку Logs: там будет видно, что ответил GigaChat. Скинь ошибку, разберемся

## Шаг 4. Аналитика (по желанию)
В `index.html` найди строку `const POSTHOG_KEY = ""` и вставь Project API key из PostHog. Будут видны события: загрузил файл, открыл итоги, поделился, нажал AI. Содержимое чатов не отправляется

## Шаг 5. Проверка из России
Открой сайт с мобильного интернета без VPN. Если не открывается, напиши, подберем хостинг в РФ

## Как поменять фото
Фото лежит в корне репозитория: `me.jpg` (контурная версия) и `me-real.jpg` (оригинал, показывается при наведении). Чтобы заменить: в GitHub открой `me.jpg` → три точки → Delete file → Commit. Потом Add file → Upload files → загрузи новое фото с тем же именем `me.jpg`. Лучше вертикальное, примерно 4:5
